Create a Register (GPIO)

This instruction creates a bus or register for input/output GPIOs. You can combine between 2 and 16 GPIOs. The internal definition is a bus, and it is bidirectional. You can change it from an input to an output port without problems.

Syntax:


create_reg REG_NAME, GPIO1,GPIO2,....GPIO16

  • REG_NAME: Any name you choose for the register.
  • GPIO1,GPIO2,....GPIO16: Any digital input or output GPIO.

Note:
You cannot create a register for an analog GPIO. This instruction works only for digital GPIOs. The register name is saved globally. Changing the direction of the port (input or output) is supported.
Example:
create_reg rg, PB_0, PB_7, pb_14; REM LED1,2,3 myvalue=0b111;     rem Initialize myvalue with 0b111;
put rg, myvalue;     rem send the value to all three LEDs;
