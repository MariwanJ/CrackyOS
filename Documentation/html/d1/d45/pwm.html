Generate PWM Signal

This instruction generates a PWM signal defined by a period and a pulse width.

Syntax:

pwm PinName, period, pulswidth

  • period: Period is a float number in seconds which represent the time between two consecutive low to high transitions in sec.
    Make sure that you choose the correct port name. You find the pin names in the manual/datasheet of your board.
  • period: The period is a floating-point number in seconds that represents the time between two consecutive low-to-high transitions. Make sure that you choose the correct port name. You can find the pin names in the manual or datasheet for your board.
  • Pulse Width: The pulse width is a floating-point number in seconds that represents the time the signal remains high.

Example:
pwm PA_0,0.002,0.001     rem square wave generated at pin PA_0
