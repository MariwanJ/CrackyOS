Variables

Variables are used to store information that can be referenced and manipulated in a script program. Variables inside the system are global.
To free memory, use the del command. Some names are reserved for instructions command. Look at the instruction commands to know the reserved name list.

Addition between array variables is not implemented. An array can be passed to a function using its variable name. The function can read all values represented by the variable if it is an array. Variable names are not case sensitive. This means that for example:
MyVariable is equal to myvariable and they are the same name of one variable.

This system doesn't care about the case of the letters used in the script program. They all will be changed to lower case during the initialization and run of the script program.

Syntax:

MyVariable=arithmetic expression;
OR
MyVariable[ ]={nr1,nr2...etc};
Example:
var1=0;     rem define and initialize var1 to be zero
var2=var1+(5*2)^2;
var2++;
var1=var2/100;
array[  ]={10,10,10,10,10,1};
array[4]=9;
neVar= log(10);
delete var2; rem Free up the memory

Note:
Before using any variable in the right side in any arithmetical operation/calculation, you need to assign a value to the variable before that. Not assigning a value to the variable, means that you are using a variable that doesn't exist in the script. This will cause a fatal error.
