I2C Send

This instruction sends data to an I2C device (master or slave). The instruction uses the standard I2C_SCL and I2C_SDA definitions.

Syntax:

i2c_send MASTER/SLAVE, address, DATA_tobesend, lengthOfData;

  • MASTER/SLAVE:    0= Master , 1=Slave
  • address:               Address of the MASTER/SLAVE
  • DATA_tobesend: You must provide a variable containing the data to send. It might be an array of characters.
  • lengthOfData:     Length of the message or data

Example:
i2c_get 1, 1222, myvalue,2;     rem read from the slave 2 bytes
print myvalue;               rem send the value to terminal
