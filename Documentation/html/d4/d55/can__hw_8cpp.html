int token_can_get ( )

CAN get instruction The syntax of this script is as follow:

can_get PinName1, PinName2, FREQ, CANID, VARIABLE PinName1 1) CAN H pin as defined in the manual. PinName2 2) CAN L pin as defined in the manual. ResultVariable 3) A variable keep the results of the can write process( 0 if write failed, 1 if write was successful) FREQ 4) Frequency of the CAN bus VARIABLE 5) Data received by this device (an array of 8 bits)

◆ token_can_send()

int token_can_send ( )

CAN send instruction Important Note: Can devices must get isolated power supply. Don't connect GND of the CAN transmitter to the Nucleo GND. Use external adapter (for TJA1051T VCC = +5V). The syntax of this script is as follow:

can_send PinName1, PinName2,ResultVariable ,FREQ, CANID, CAND_DATA0,...CAN_DATA8 PinName1 1) CAN RD pin as defined in the manual. PinName2 2) CAN TD pin as defined in the manual. ResultVariable 3) A variable keep the results of the can write process( 0 if write failed, 1 if write was successful) FREQ 4) Frequency of the CAN bus CANID 5) Address of the can device CAN_DATA0..8 6) An array of 8 bytes representing the data to be sent via can bus.
