For loop

A for loop is a repetition control structure that allows you to efficiently write a loop that needs to execute a specific number of times. Only two nested for loops are allowed

Syntax:

for(init, condition, increment/decrement)

  • init: You must provide a variable for the loop and initialize it; for example, myvar=0.
  • condition: The condition could be one of the following:
    • comparison between the first variable and a value.
    • comparison between the first variable and another variable.
    • comparison symbols allowed (<,>,<=, >=, !=, ==).
For loop

Example:
Ex1:
  for(i=0,i<20,i++) {print i;};     rem print to the terminal i-values
EX2:
  for(i=100,i>0,i–) {print i;};     rem print to the terminal i-values
EX3:
  myVar=20;
  for(i=100,i>myVar,i–) {print i;};     rem print to the terminal i-values

Note:

  • You must use Curly Brackets '{...}' after for-loop statement.
  • More than two nested for loops are not allowed. However, you can combine a while loop with a for loop to achieve the required iterations.
  • You must initialize the variable used inside the for loop instruction. Missing that will cause run-error.
  • Comma is used inside for instruction, not semicolon as for C/C++
