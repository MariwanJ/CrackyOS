CAN Get

This instruction reads data from a CAN device. You might need to put the instruction in a loop to make sure that data is read correctly from the CAN device.

  • The returned result is 1 when the data is received successfully.
  • The returned result is 0 when the data is not received successfully.

    Syntax:

can_get PinName1, PinName2, FREQ, CANID, VARIABLE;

  • PinName1: CANRD pin name
  • PinName2: CANTD pin name
  • FREQ       : CAN Bus frequency
  • CANID      : CAN ID. This represents the CAN device ID
  • VARIABLE_NAME: A Variable name is required. The results will be saved in this variable (might be an array of int).

Example:
while(1)
 {
 can_get pb_8, pb_9, 100000,0x10,result;
 if (result!=0){
   print result;
  }
  delay 100,msec;
}
