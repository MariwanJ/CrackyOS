◆ readConfigFile()

int readConfigFile ( void  )

This function will read the configuration saved on the SD-Disk If the configuration file is not there it will return the following integer -1 : DefaultFile is not found or bad -2 : BaudRate is not found or bad -3 : InterActiveMode is not found or bad

-10 : File not found -20 : File size is wrong. The file is corrupted.

In all these cases, default configuration file should be re-created.
