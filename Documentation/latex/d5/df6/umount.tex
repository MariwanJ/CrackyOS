\doxysection{Umount (unmount an SD card)}
\hypertarget{umount}{}\label{umount}\index{Umount (unmount an SD card)@{Umount (unmount an SD card)}}
This instruction is used to unmount an SD card.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } umount ~\newline
 or~\newline
 unmount 

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted and mounted before using this instruction.
