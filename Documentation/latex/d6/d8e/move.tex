\doxysection{Move (move a file from one directory to another)}
\hypertarget{move}{}\label{move}\index{Move (move a file from one directory to another)@{Move (move a file from one directory to another)}}
This instruction is used to move a file from one folder to another on the SD card.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{move \texorpdfstring{$<$}{<}source\+\_\+filename\+\_\+with\+\_\+path\texorpdfstring{$>$}{>} \texorpdfstring{$<$}{<}destination\+\_\+filename\+\_\+with\+\_\+path\texorpdfstring{$>$}{>}}}

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted. The card must be mounted before using this instruction.
