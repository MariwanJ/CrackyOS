\chapter{\"{}\+Known issues\"{}}
\hypertarget{04_known_issues}{}\label{04_known_issues}\index{\"{}Known issues\"{}@{""Known issues""}}
The following issues and limitations are known\+:


\begin{DoxyItemize}
\item Hardware\+:
\begin{DoxyItemize}
\item ARM CORTEX 3 and above hardware -\/ mbed enabled.
\item Sufficient amount of Flash memory and RAM.
\item SD Card and SD Card reader.
\item Power supply 3V3
\item Execution speed is slower compared to compiled code as this system has an interpreter engine.
\end{DoxyItemize}
\item Software\+:
\begin{DoxyItemize}
\item Eclipse \+: Necessary to compile the system if you wish compile locally. See the Eclipse preparation section for more details.
\item Eclipse \+: Necessary to compile the system if you wish to compile locally. See the Eclipse preparation section for more details.
\item MBED-\/\+OS \+: On-\/line IDE. Notice that you cannot generate debug information from the online compiler.
\item MBED-\/\+OS \+: Online IDE. Notice that you cannot generate debug information from the online compiler.
\end{DoxyItemize}
\item System limitations\+:
\begin{DoxyItemize}
\item Arithmetic operations are not supported inside while or for loops.
\item Numbers are rounded automatically during arithmetic operations. 
\end{DoxyItemize}
\end{DoxyItemize}
