\doxysection{Copy (Copy a file)}
\hypertarget{copy}{}\label{copy}\index{Copy (Copy a file)@{Copy (Copy a file)}}
This instruction is used to copy a file. You cannot use it inside script program.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape }
\begin{DoxyItemize}
\item copy $<$source\+\_\+\+FN$>$ $<$destination\+\_\+\+FN$>$
\end{DoxyItemize}

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted. The card must be mounted before using this instruction.
