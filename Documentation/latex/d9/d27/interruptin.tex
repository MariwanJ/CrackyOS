\doxysection{Interrupt\+In}
\hypertarget{interruptin}{}\label{interruptin}\index{InterruptIn@{InterruptIn}}
This instruction is used to create an interrupin GPIO. Associated function must be defined before defining the interrupin. ~\newline
 Keep in mind that interrupt function should not take a lot of time to execute it.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{interrupin PINNAME, Function\+Name }} ~\newline
 or~\newline
 {\bfseries{interrupin PINNAME Function\+Name }}~\newline
