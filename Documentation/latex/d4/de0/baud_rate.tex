\doxysection{Baud Rate}
\hypertarget{baud_rate}{}\label{baud_rate}\index{Baud Rate@{Baud Rate}}
Determine the baud rate used in the system.~\newline
 {\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{ baud\+\_\+rate VALUE}}~\newline

\begin{DoxyItemize}
\item {\bfseries{VALUE\+:}} Any integer value from 110 to 256000 bits per second, including 110, 300, 600, 1200, 2400, 4800, 9600, 14400, 19200, 38400, 57600, 115200, 128000, and 256000.
\end{DoxyItemize}

{\itshape {\bfseries{ Example\+: }} } ~\newline
 baud\+\_\+rate 115200; ~~~  rem change the baud rate to 115200 bit/sec.~\newline
