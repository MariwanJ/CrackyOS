\doxysection{Mount (mount a SD-\/\+Card)}
\hypertarget{mount}{}\label{mount}\index{Mount (mount a SD-\/Card)@{Mount (mount a SD-\/Card)}}
This instruction is used to mount an SD card.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } mount 

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted before using this instruction.
