\doxysection{Format SD disk}
\hypertarget{format}{}\label{format}\index{Format SD disk@{Format SD disk}}
This instruction formats the SD card.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{ format; }}~\newline


{\itshape \doxyparagraph*{Warning\+: }}

{\itshape } This instruction cannot be stopped or reversed.

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted before using this instruction.
