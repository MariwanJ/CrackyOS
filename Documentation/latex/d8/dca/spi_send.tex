\doxysection{SPI Send}
\hypertarget{spi_send}{}\label{spi_send}\index{SPI Send@{SPI Send}}
SPI protocol communication instruction. This instruction sends data or an array to an SPI device and gets a response, which is saved in the provided variable.~\newline
 SPI protocol supports multiple slaves. To make this function work properly, make sure that the devices support a tri-\/state configuration when they are disabled.~\newline
 No more than one device should be on the bus at the same time.~\newline
 If you need to send several bytes (more than 16bit) to the device you target without changing the chip select signal, put the bytes you have (it doesn\textquotesingle{}t matter how many) in an array and make the communication 8bits. This will allow the spi\+\_\+send command to send the bytes one by one using only one chip select cycling (high-\/low-\/ high). This is applicable ONLY when you have a numerical array. But, Text array will be treated differently, and data will be sent byte by byte with chip select cycling per each byte.
