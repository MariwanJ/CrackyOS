\doxysection{Rem}
\hypertarget{rem}{}\label{rem}\index{Rem@{Rem}}
After REM instruction, all letters to the end of the line or to the position of finding a semicolon will be ignored~\newline
 {\itshape {\bfseries{ ~\newline
 Note\+:}} } ~\newline
 Although rem line is not executed and doesn\textquotesingle{}t affect the execution of the script program, but it will occupies the memory space. It is not recommended to use REM a lot. {\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{ rem comments ; }} ~\newline
{\bfseries{ comments\+: }} Optional. The text of any comment you want to include. A space is required between the \"{}rem\"{} -\/keyword and the comments. ~\newline
 {\itshape {\bfseries{ ~\newline
 Example\+: }} } ~\newline
  rem Sample script program 2018-\/06-\/04 ~\newline
