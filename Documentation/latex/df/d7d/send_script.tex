\doxysection{Send\+\_\+script}
\hypertarget{send_script}{}\label{send_script}\index{Send\_script@{Send\_script}}
This instruction is used to send via RS232/\+Terminal script program. You need to stop the process by sending the symbol \textquotesingle{}\#\textquotesingle{}. After that the text (script) will be saved as default script program on the SD card.

{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{send\+\_\+script script\+\_\+\+Text\# }}

{\bfseries{Note\+:}}~\newline
 An SD-\/card module must be connected to the Nucleo board through SPI, with an SD card inserted. The card must be mounted before using this instruction.
