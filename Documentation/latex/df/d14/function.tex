\doxysection{Function Definition}
\hypertarget{function}{}\label{function}\index{Function Definition@{Function Definition}}
Generic Function Implementation and declaration. Functions allow the user to structure their programs in segments of codes to perform individual tasks. They don\textquotesingle{}t share the same global variables. If any script program wants to send a value or variable to the function, user must make them as an argument to the function and function call~\newline
 They do not share the same global variables. If a script program wants to send a value or variable to a function, the user must pass it as an argument in the function call.~\newline
 ~\newline
Functions must be defined in the beginning of the script program. This will allow the system to save the definitions. Later when they are called using \"{}\+Call\"{} statement, they are executed. ~\newline
 {\itshape {\bfseries{Some notes\+:}}}~\newline
 
\begin{DoxyItemize}
\item Global variable cannot be accessed inside functions.  
\item GPIO and other peripherals can be accessed inside functions, they are visible everywhere as they are shared in the system. 
\item If you want to access (a) global variable(s), send the variable name or the value as an argument to the function. 
\item Execution of a function might be slower than running the code without a function. Global variables are backed up before calling the function. 
\end{DoxyItemize}{\itshape \doxyparagraph*{Syntax\+: }}

{\itshape } {\bfseries{ Function function\+\_\+name(arg1, arg2 ..arg5) \{ ...code ...\}}}~\newline

\begin{DoxyItemize}
\item {\bfseries{arg1,..arg5\+:}} Arguments provided to the function. It could be a string, number, a variable of array, a variable of numbers
\end{DoxyItemize}

{\itshape {\bfseries{ Warning\+: }} } 

~ Function names cannot be longer than 20 bytes. This limitation restricts the size of the number generated by the hash calculator. Keep this limit in mind when writing a script program.
