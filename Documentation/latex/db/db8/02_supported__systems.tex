\chapter{Supported Systems}
\hypertarget{02_supported__systems}{}\label{02_supported__systems}\index{Supported Systems@{Supported Systems}}
Any ARM Cortex-\/\+M3/\+M4 processor that is mbed-\/os enabled could run this system with modifications to some files. \doxysubsubsection*{Note\+:}

Some additional requirements must be taken into consideration as follows\+:
\begin{DoxyItemize}
\item Flash memory size\+: This is necessary because the compiled binary requires a specific amount of flash memory.
\item RAM size\+: This is essential to take in the account because the script program will be loaded to the memory. The size of the script program is exactly what you must have plus some more RAM for the system to run.
\end{DoxyItemize}
